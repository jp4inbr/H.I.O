# H.I.O
H.I.O. (Hub de Inteligência Operacional) Plataforma web centralizada para automação e auditoria de dados. O sistema integra 11 pipelines de processamento de arquivos (PDFs, imagens e texto) em um dashboard inteligente, convertendo rotinas operacionais manuais em fluxos de trabalho escaláveis e orientados a dados.
